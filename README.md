# csy's Minecraft

[打开游戏](https://csy109.github.io/csy-minecraft/) · [项目源码](https://github.com/CSY109/csy-minecraft)

原生 JavaScript / WebGL2 网页方块沙盒，无需安装应用、无需构建。电脑使用键盘鼠标，手机自动启用触控界面，同一个网址自动适配。双击 `index.html`，或在项目目录运行 `npm start` 后打开 <http://127.0.0.1:3000>。

手机使用横屏布局，竖屏时显示旋转提示并暂停游玩；浏览器支持时，点击开始会进入全屏并锁定横屏。左侧为灰色像素十字方向键，中间潜行，右侧为跳跃、挖掘和使用图标；红心与饥饿分别放在左上和右上，底部保留快捷栏及「…」背包键。手机与电脑仍使用同一网址，无需选择设备版本。

首页使用游戏内实景和带苦力怕元素的石质标题，`csy's` 以小字显示。种子、渲染距离和音量收在「设置」，操作说明收在「操作」，不在封面堆叠文字。

## 玩法

- **生存**：有限物品、采集掉落、工作台合成、简易冶炼、生命、饥饿、食物回血、摔落和溺水伤害。死亡后点击重生，背包保留。
- **环境伤害与燃烧**：按整个身体与方块的相交范围判断接触，包括边缘碰到火或熔岩的情况；液体还会检查实际水面高度。生存玩家和动物碰火立即受伤并着火，熔岩每半秒造成 4 点伤害；离开火源后继续燃烧，入水灭火。动物身上显示经典火焰，玩家第一人称视野边缘显示火焰，死亡仍使用侧翻动画。玩家和动物从超过 3 格的高度落地会按落差扣血，水和熔岩缓冲摔落，创造玩家免伤。
- **创造**：无限方块与物品、自由飞行、刷怪蛋和时间加速。按 Esc 在暂停菜单直接切换生存 / 创造，无需刷新；保留世界、位置、生物、背包与生命状态，两种模式各自记住快捷栏。返回生存会退出飞行。
- **动物**：猪、牛、羊会游走，受击逃跑。死亡时先闪红、侧翻倒下，短暂停留后化为白色颗粒消失。手持苹果可吸引动物，击败动物获得肉，羊还掉落羊毛。
- **小怪**：夜间在周围生成僵尸、蜘蛛、苦力怕。僵尸在露天日照下受伤，苦力怕靠近后蓄力爆炸并破坏附近普通方块。蜘蛛掉落蛛丝，可用来制作弓。
- **武器与工具**：木、石、铁、钻石四档镐、斧、锹、剑，以及弓和箭。弓按住右键拉弓、松开发射，使用三阶段经典贴图；蓄力越久射程与伤害越高，约 1 秒拉满。生存发射才消耗箭，创造无限箭；切换物品、暂停或打开背包会取消拉弓。近战有攻击冷却，方块阻挡近战和投射物。
- **爆炸箭**：手持弓按 R 切换箭种，或在手持弓时点击背包里的箭。4 支普通箭 + 1 份火药合成 4 支爆炸箭，击败苦力怕获得火药。爆炸箭有红色箭头，命中方块或生物后破坏以命中格为中心的 5×5×5 方块范围，对与范围相交的生物和生存玩家造成固定 20 点伤害（不叠加直击伤害），伴随爆炸声、火花和烟尘。基岩、黑曜石、传送门和液体保留；箭过期消失不会引爆。蓄力影响飞行速度，不改变爆炸伤害和范围；选定箭种用完后停止发射，可按 R 切换。
- **更多方块**：铁块、雕刻南瓜、金矿石、钻石矿石、金块、钻石块、羊毛、苔石、黏土、黑曜石、工作台，加上下界地狱岩、灵魂沙、地狱砖、荧石、石英矿、岩浆块、熔岩、传送门、火把和火，共 43 种非空气方块。
- **照明**：火把亮度 14，荧石、火、熔岩亮度 15，岩浆块亮度 3，传送门亮度 11。光逐格衰减，被不透明方块遮挡，穿过树叶和水时衰减更快；光照能跨区块传播，移除光源会恢复黑暗。光照计算和地形模型一起在后台执行。煤炭与木棍合成 4 个火把，火把需要脚下支撑。打火石可以点火；普通地面上的火约 12 秒后熄灭，地狱岩上的火持续燃烧，附近有水会灭火。
- **流体与重力**：使用固定 20 Hz 游戏刻。水每 5 刻更新，优先寻找附近能向下流的路径，平地最多扩散 7 格；支持两个相邻水源补成新水源、断源消退、平滑衔接的水面与推动玩家的水流。主世界熔岩每 30 刻更新、扩散 3 格，下界熔岩每 10 刻更新、扩散 7 格。沙子和沙砾失去支撑后延迟 2 刻变成下落实体，按每刻重力和阻尼运动，画面进行插值，落地按上下顺序堆积。
- **下界**：独立的洞窟地形、熔岩湖、荧石、石英矿和灵魂沙。黑曜石门框用打火石激活，进入后生成安全落脚点和返回门。主世界、下界各自保留方块改动和生物状态；熔岩会伤害玩家，灵魂沙减速，水在下界蒸发。当前下界以地形探索为主，没有下界专属怪物与要塞。
- **音效**：78 段经典录音，分成 46 组，覆盖不同材质的脚步和挖掘、动物与小怪、刀剑和弓箭、进食与受伤、入水和游泳、水流、熔岩冒泡、沙石落地、传送门待机与穿越、洞窟环境声。随机变体避免同组连续重复，环境声按距离衰减并带立体声方向；暂停会停止环境循环，菜单可调整音量或静音。

武器、工具、食物、刷怪蛋和新增方块使用经典 Minecraft 1.12.2 PNG 贴图，动物、小怪和傀儡使用逐面展开的原版皮肤。武器模型沿不透明像素边缘生成厚度，生物按像素尺寸建立头部、身体、四肢、鼻子和羊毛层，并以关节旋转行走。

弓使用独立的第一人称持握动作：待机时竖持在右侧，拉弓时平滑抬起，箭头朝前，弓臂与弓弦保持可见；放箭时轻微回弹并收回，不套用刀剑的挥砍动作。打开背包、暂停或切换物品会清除拉弓姿态。

贴图来自 [Mojang 官方版本清单](https://piston-meta.mojang.com/mc/game/version_manifest_v2.json) 指向的 1.12.2 客户端，导入时验证客户端 SHA-1。具体来源记录在 `assets/classic-source.json`，导入脚本为 `tools/import-classic-textures.py`。图像版权属于 Mojang。贴图已嵌入本地 JavaScript，运行时无需联网；地形原有的程序生成贴图保留。

声音来自同版本官方资产索引，每段导入时校验 SHA-1，版权属于 Mojang。来源见 `assets/classic-sound-source.json`，可用 `tools/import-classic-sounds.py` 重新打包。音频也已嵌入本地资源，可离线运行。

本项目的流体与落沙规则以 Java 版经典机制为参照，核心场景用自动化测试验证；双水源行为可参见 [Minecraft 官方水方块介绍](https://www.minecraft.net/en-us/article/block-week-water)，相邻流体和下落方块的兼容处理参考 [Forge 1.12 流体补丁](https://github.com/MinecraftForge/MinecraftForge/blob/1.12.x/patches/minecraft/net/minecraft/block/BlockDynamicLiquid.java.patch) 与 [下落方块补丁](https://github.com/MinecraftForge/MinecraftForge/blob/1.12.x/patches/minecraft/net/minecraft/entity/item/EntityFallingBlock.java.patch)。这里覆盖项目已有方块，未实现活塞、含水方块和红石等原版系统。

## 下界传送门与铁桶

用黑曜石搭建外宽 4 格、外高 5 格的竖直门框，内部留出 2×3 的空白，四个角可省略，至少用 10 块黑曜石。门可沿 X 或 Z 轴搭建，也支持更大的矩形门框（内部最长 21 格）。用打火石右键点燃门框内侧，再站进紫色门；生存需要等待 4 秒，创造几乎立即传送。对面的返回门与原门连接，破坏门框会使门熄灭。

打火石需要 1 铁锭和 1 燧石，挖沙砾有 15% 概率获得燧石；铁桶需要在工作台附近用 3 铁锭合成。空桶右键收集水源或熔岩源，装满的桶右键倾倒后返还空桶，流动中的液体不能直接装桶。创造模式可直接选择黑曜石、打火石、水桶和熔岩桶。

## 开始生存

1. 按住左键采集原木，按 **E** 打开背包。
2. 点击配方：原木变木板，木板制作木棍和工作台。每个配方显示材料持有量与所需量。
3. 点击背包中的工作台，把它装到当前快捷栏，用右键放在身旁。
4. 在工作台 4 格范围内制作木镐，采圆石制作石镐，再开采铁矿。粗铁与煤炭通过背包里的简易冶炼配方变成铁锭。
5. 白天准备工具、食物和住所。右键食用食物，饥饿值足够高时逐渐回血。生存开局带 4 个苹果。

挖掘时，方块表面会出现十个阶段的经典裂纹，期间落下小碎屑，完成后碎成颗粒。挖掘速度随方块硬度和工具变化。换目标、切换工具或松开左键会清除裂纹并重新计时；水下挖掘更慢。镐挖石矿、斧砍木材、锹挖泥沙更快，工具等级越高越快。石镐能采铁，铁镐能采金和钻石，钻石镐能采黑曜石；等级不足时不掉落，等级要求可在背包帮助中查看。生存无法破坏基岩。用锹挖积雪草方块还会获得雪块。

生存界面使用经典像素红心、鸡腿和快捷栏，支持半颗红心、半格饥饿和水下气泡。物品名称仅在切换时短暂显示，操作与合成说明收纳在暂停菜单和背包的折叠帮助中；游玩时不显示挖掘进度条、目标文字或顶部说明。

冶炼采用直接消耗煤炭的简易配方；当前没有炉子等待过程或工具耐久。区块卸载重载后保留本局内的方块改动，刷新网页会创建新的游戏，不提供磁盘存档。

## 召唤傀儡

**铁傀儡**：4 个铁块搭 T 形，最后在中间顶部放雕刻南瓜。身体可沿 X 或 Z 轴，下排左右保持空旷，周围留出空间。

```text
       南瓜
铁块   铁块   铁块
       铁块
```

**雪傀儡**：竖直叠 2 个雪块，最后放雕刻南瓜。

```text
南瓜
雪块
雪块
```

成功后搭建材料会转化为傀儡。铁傀儡近战攻击小怪，雪傀儡远程投掷雪球。南瓜自然生长于草地；雪山可采雪块，也可以用锹采积雪草方块获得雪块。E 背包底部也有搭建指南。

## 操作

手机：横屏，左侧十字键移动、滑动场景转动视角，按住两个方向可斜走。中间按钮潜行，右侧向上箭头跳跃，镐键挖掘或攻击，方块键使用或放置。弓按住方块键蓄力、松开发射；上方双向箭头切换箭种。快捷栏右侧「…」打开背包，上方暂停键打开菜单；创造模式显示飞行按钮，飞行时跳跃上升、潜行下降。背包支持搜索、合成和触摸滚动。转回竖屏、暂停或失焦都会清除按住的操作。

电脑：保留键鼠操作，快捷栏增加淡色数字键提示，准星缩小；设置中可调整视野（60–100°）和视角灵敏度（25–200%）。说明仍收在操作面板，游玩画面没有常驻说明文字。

| 按键 | 操作 |
| --- | --- |
| WASD / 鼠标 | 移动 / 视角 |
| 空格 / Shift / Ctrl | 跳跃 / 潜行 / 疾跑 |
| 按住左键 | 挖掘或近战攻击 |
| 右键 | 放置、食用或使用刷怪蛋；手持弓时按住蓄力、松开发射 |
| R | 手持弓时切换普通箭 / 爆炸箭 |
| 滚轮 / 1–9 | 切换快捷栏 |
| 中键 | 选择目标方块，生存需要背包中已有 |
| E / Esc | 背包与合成 / 暂停 |
| F3 | 调试信息 |
| 双击空格 / T | 创造飞行 / 创造时间加速 |

创造飞行时，空格上升，左 Shift 或右 Shift 下降，松开后悬停，同时按住空格与 Shift 会抵消上下输入，下降到地面后自动退出飞行。

鼠标重新锁定时丢弃第一笔定位位移，并过滤非有限值及窗口级的异常跳变；正常鼠标移动直接响应。游玩时的区块生成与模型重建放在后台 Worker，完成后校验区块版本，避免旧模型覆盖刚挖掘或放置的方块。后台线程也支持直接打开 `index.html`；浏览器不支持 Worker 时使用同步加载后备逻辑。

沙子和沙砾只根据同一 X / Z 列正下方的方块判断支撑，侧面、斜下方开洞不会触发下落。移除直接支撑后等待两刻开始竖直下落；支撑及时恢复会取消等待中的下落，同一刻新出现的支撑也会重新检查。水和非实体植物不能支撑沙子。

暂停、打开背包或窗口失焦退出鼠标锁定后，游戏时间、生物 AI、投射物和生存状态停止推进。

## 验证

安装测试依赖后运行：

```sh
npm install
npx playwright install chromium
npm test
```

也可以用环境变量 `TEST_BROWSER` 指定本机 Chrome / Edge 可执行文件，使用 `PLAYWRIGHT_MODULE` 指向已有的 Playwright 包。测试在独立的无头浏览器中运行实际 WebGL 页面，覆盖资源与合成、工具效率与掉落限制、放置消耗、两种方向的傀儡搭建、近战与远程攻击、傀儡守护、生存伤害、夜间生成、区块改动保留、暂停和物品搜索。截图写入 `test-results/`。

专项检查：`node tests/world-worker-source.cjs` 检查后台代码隔离运行；`node tests/run-world-jobs.cjs` 检查后台生成、流体模型及异步改动保留；`node tests/profile-world.cjs` 输出同步区块生成、重建和物理更新的耗时。完整游戏测试还覆盖锁定鼠标时的视角跳变、侧面与斜下方开洞、支撑恢复，以及 `file://` 模式的后台线程运行。

`node tests/run-mobile.cjs` 使用原生多点触控协议验证手机操作；`node tests/run-deployed.cjs` 直接检查已发布网站的电脑版、自动适配、资源加载、后台线程、背包与模式切换，以及手机多指移动、转动视角、放置火把、飞行和射箭。可用环境变量 `PLAY_URL` 指定待检查的网站。

`node tests/run-hazards-controls.cjs` 是本次横屏操作与伤害修复的定向检查：验证身体边缘接触、持续燃烧、入水灭火、三种动物被熔岩烧死后的动画、实际摔落、水中缓冲、火焰渲染、电脑设置，以及两种横屏尺寸下的按钮布局和原生多指输入。
